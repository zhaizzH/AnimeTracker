# 精简 Java 后端中文注释规范

## 目标
让 Java 中文注释自然直观，减少模板话，同时保留准确、完整的调用契约

## 已确认要求
- 仅 Java 后端：声明使用 Javadoc，方法体内说明使用普通注释
- 中文说明末尾不加句号；多句说明保留必要的句间标点，代码、URL、版本号中的点号不变
- 声明全覆盖，保留必要的参数、返回值、异常以及单位、空值、特殊值和失败条件；实现方法按约定继承接口文档
- 先调整规范和检查器相关要求，存量业务注释另行整理

## 验收标准
- [x] 删除规范中“以中文句号结束”的旧要求，示例采用自然中文和无末尾句号
- [x] 示例覆盖类型、字段、方法标签、方法体注释；精简后不丢失必要契约
- [x] 合法无句号 Javadoc 通过检查，缺文档、标签错配和既有机械模板继续被拒绝
- [x] 旧存量带句号注释保持门禁兼容，检查器回归与适用的声明/doclint 校验通过

## 范围外
不改业务行为，不调整前端/Python 注释，不做全库标点替换，不新增 CI 接入
