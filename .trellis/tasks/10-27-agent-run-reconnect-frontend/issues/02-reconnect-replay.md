# 02: 刷新/切会话后接着看

**What to build:** 用户在回答生成到一半时刷新页面，或切到别的会话再切回来，能接着看到正在生成的回答继续增长，而不是盯着一片空白等后端跑完。已经落库的历史内容与实时回放的内容不重复出现。

**Blocked by:** None (can start immediately)。与 01 改同一个 hook 文件，实际排期建议顺序执行。

**Status:** done

- [x] 进入某会话时查询该会话是否有进行中的 run
- [x] 有 run 在跑 → 新建一个**空**的 assistant 气泡，从头订阅该 run 的增量，正文只出现一次
- [x] 已结束 / 已失败 / 已取消 → 不订阅，直接读历史；失败态额外给「上次回答未完成」提示
- [x] 增量游标用「已收到的事件帧数」，与文本长度无关；有测试用「一帧长文本 + 一帧短文本」证明游标不随字符数跳变
- [x] 回放路径与实时路径共用同一把 `is_end` 锁：收到结束帧后不再累积任何内容
- [x] 回放过程中出现「实时缓冲已截断」的降级信号时，给用户提示「部分实时内容已过期，完整回答见历史」
- [x] 切走会话时取消订阅，且不留残留气泡
- [x] 既有 SSE 行为不回归：事件白名单、`is_end` 锁、401/403 文案
